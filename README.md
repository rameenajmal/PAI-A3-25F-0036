# PAI-A3-25F-0036

Assignment 3, Programming for AI.

## How to run
1. Install numpy, pandas, matplotlib and pillow.
2. Keep the CSV files in the data/ folder.
3. Open Assignment3_Programming_for_AI.ipynb in VS Code.
4. Click Run All and let it run from top to bottom.

The dashboard (PNG and PDF) and wave.gif are saved in the outputs/ folder.

## One hard thing
The hardest part was making the graphs and keeping track of all the details. Each plot needed many small settings, like axes, colorbars and labels, and one small mistake changed the whole figure.
